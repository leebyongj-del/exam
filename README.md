# 고사 운영 도우미

명지중학교 고사 운영 업무(시험 일정 → 과목별 시험범위 수합 → 통합 문서 → 학업성적관리위원회)를
한 화면에서 처리하는 웹앱입니다.

- **과목 선생님**: 링크만 열면 바로 시험범위를 입력합니다. 로그인이 없습니다.
- **관리자(교무부 담당)**: 관리자 번호로 들어가 시험 일정·시간표를 만들고 문서를 받습니다.
  번호 확인은 Firebase 보안 규칙이 하므로 화면을 우회해도 일정은 바뀌지 않습니다.

## 주요 기능

- 시험 시작일만 넣으면 범위 수합부터 성적통지표 배부까지 일정 자동 생성 (요일·이의신청 일수 자동 계산)
- 고사 시간표 → 시험범위 수합 목록과 일정표의 시험일 행에 자동 반영
- 과목별 입력 현황, 입력 마감
- ‘시행 일정 및 성적 처리 운영 방안’, ‘제출서류 및 유의사항’을 원본 한글 양식대로 만들어 한글(.hwpx)·워드(.docx)로 받기
- 학업성적관리위원회 회의록
- 백업 내보내기 / 가져오기 (.json)

## 처음 한 번 설정하기 (Firebase)

설정 전에는 이 주소에서 입력한 내용이 **그 브라우저에만** 저장됩니다. 여러 선생님이 함께 쓰려면 아래를 설정하세요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (관리하는 선생님의 구글 계정이면 됩니다)
2. **Firestore Database → 데이터베이스 만들기** — 위치 `asia-northeast3 (서울)`, 프로덕션 모드
3. **Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정
   (선생님들 눈에는 로그인 화면이 보이지 않습니다. 접속하면 화면 뒤에서 자동으로 처리됩니다)
4. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`)** 으로 앱 등록 → 나오는 `firebaseConfig` 값을
   이 저장소의 `firebase-config.js`에 붙여 넣기
5. **Firestore Database → 규칙** 탭에 `firestore.rules` 전체를 붙여 넣고 **게시**
6. 저장소 **Settings → Pages** → Deploy from a branch → `main` / `(root)` → 저장
7. 웹앱 주소에 들어가 **관리자 → 관리자 번호 처음 정하기**를 바로 해 두기 (영문+숫자 8자리 이상)
   - 번호가 정해지기 전에는 누구든 처음 번호를 정할 수 있으니, 6번 직후에 바로 해 두세요.
8. (기존 자료 옮기기) Claude 웹앱 → 더보기 → **백업 내보내기** → 이 웹앱 관리자 화면 → 더보기 → **백업 가져오기**

## 담당자가 바뀌면

- 관리자 번호만 새 담당자에게 알려 주면 됩니다.
- 새 담당자는 **더보기 → 관리자 번호 변경**으로 번호를 바꿉니다. 바꾸면 이전 번호로 들어와 있던 기기는 관리자 권한이 모두 풀립니다.
- Firebase 프로젝트는 만든 사람의 구글 계정에 있습니다. 관리를 넘기려면 Firebase 콘솔 → 프로젝트 설정 → 사용자 및 권한에서 새 관리자를 추가하세요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹앱 전체 (화면, 한글·워드 문서 만들기) |
| `firebase-bridge.js` | Firebase 연결 (익명 로그인, 저장소, 관리자 번호 확인) |
| `firebase-config.js` | Firebase 설정값 — 4번에서 붙여 넣는 곳. 공개되어도 괜찮은 값입니다 |
| `firestore.rules` | 보안 규칙 — 5번에서 Firebase 콘솔에 붙여 넣는 내용 |

> 학생 개인정보나 성적은 입력하지 마세요. 시험범위와 일정만 다루는 용도입니다.
