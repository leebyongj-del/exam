# 고사 운영 도우미

명지중학교 고사 운영 업무(시험 일정 → 과목별 시험범위 수합 → 통합 문서 → 학업성적관리위원회)를
한 화면에서 처리하는 웹앱입니다.

## 주요 기능

- **시험 일정**: 시험 시작일만 넣으면 범위 수합부터 성적통지표 배부까지 일정이 자동으로 채워집니다.
  요일은 날짜에서 자동 계산되고, 이의신청 ‘○일간’은 등교일 기준으로 계산됩니다.
- **고사 시간표**: 입력한 과목이 시험범위 수합 목록과 일정표의 시험일 행에 자동으로 들어갑니다.
- **시험범위 수합**: 과목 선생님이 직접 입력하고, 과목별 입력 현황·입력 마감을 관리합니다.
- **통합 문서**: ‘시행 일정 및 성적 처리 운영 방안’, ‘제출서류 및 유의사항’을 원본 한글 양식대로 만들어
  한글(.hwpx)·워드(.docx)·HTML로 내려받습니다.
- **학업성적관리위원회**: 심의 결과를 적으면 회의록이 만들어집니다.
- **역할 구분**: 시작할 때 관리자 / 과목 담당 교사를 고릅니다. 관리자는 관리자 번호가 필요합니다.
- **백업**: 더보기 → 백업 내보내기 / 가져오기로 모든 고사와 시험범위를 파일 하나로 옮깁니다.

## 저장 방식

| 여는 곳 | 저장 |
|---|---|
| Claude에서 공유한 링크 | 공유 저장소 — 모든 선생님의 입력이 한곳에 모임 |
| 이 저장소의 GitHub Pages 주소 | 이 기기의 이 브라우저에만 저장 (1인용) |

GitHub Pages에서 여러 선생님이 함께 쓰려면 Firebase 같은 공유 저장소 연결이 필요합니다. (추후 작업)

## 파일

- `index.html` — 웹앱 전체 (화면, 한글·워드 문서 생성 포함). 따로 설치할 것이 없습니다.
